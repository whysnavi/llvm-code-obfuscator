# Supporting Documents

This folder contains supporting materials referenced from the main project README:

- **`llvm_ijraset_certificate.pdf`** — Publication certificate for the IJRASET paper (Paper ID IJRASET79512).
- **`demo_commands_cheatsheet.html`** — Step-by-step command reference for running the obfuscator on all sample programs and interpreting the output.
- **`terminal_output.jpeg`**, **`before_after_ir_comparison.jpeg`**, **`metrics_chart_sample_program.jpeg`** — Screenshots demonstrating the pipeline running end-to-end, embedded in the main [README](../README.md#-screenshots).
